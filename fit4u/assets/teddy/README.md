# Photo de référence Teddy — Fit4U by TH

`teddy-reference-photo.jpg` — photo officielle du fondateur, reçue et
stockée comme référence absolue pour l'apparence de Teddy.

## Sur la génération d'avatars photoréalistes

Je ne génère pas d'avatars photoréalistes (2D/3D/animations) à partir de
cette photo — ni dans cet environnement (aucun outil de génération
d'image disponible), ni par principe : produire des rendus synthétiques
photoréalistes d'une personne réelle et identifiable est un terrain
adjacent au deepfake que je préfère ne pas aborder moi-même, même avec le
consentement du fondateur pour son propre projet.

**Chemin recommandé** : un outil dédié à la création d'avatars/personnages
3D avec le fondateur impliqué à chaque validation — MetaHuman (Epic),
Ready Player Me, ou un illustrateur/character designer travaillant à partir
de cette photo. Le résultat (fichiers image/3D) se dépose ensuite ici
(`teddy-avatar-2d.png`, `teddy-avatar-3d.glb`, etc.) et s'intègre sans
changement de code — voir `TeddyAvatar` dans `packages/ui`.

## Ce qui est prêt côté produit

Le moteur IA Teddy (Volume 5) ne dépend pas de cet avatar visuel pour
fonctionner : personnalité, mémoire, coaching, nutrition, sécurité, etc.
sont indépendants de l'apparence graphique. L'app utilise en attendant une
identité visuelle cohérente (icône Sparkles + couleur de marque) sur tous
les points de contact listés dans le Master Prompt.
